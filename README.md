# Active Directory

Репозиторий содержит пошаговую инструкцию по созданию учебной лаборатории Active Directory на виртуальных машинах. Инструкция ведется по мере выполнения и проверки этапов.

Сведения о подготовке VMware, установке Windows Server и его текущей базовой и сетевой настройке находятся в [инструкции по развертыванию сервера](server-setup.md).

> Инструкция предназначена для лабораторной среды и не заменяет проектирование отказоустойчивой и безопасной production-инфраструктуры.
